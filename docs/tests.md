# 二维码插件测试（v0.2.0）

- `qr_tests`：编码矩阵、版本和容量边界、ECC、文本分类、渲染颜色和留白、设置回退、保存文件名冲突。
- `tools/verify/hostsim.py`：JSON-RPC 初始化、文本查询、已删除命令返回空结果/空动作、剪贴板图片、连开两个预览共存且错开摆放、窗口前台及键盘焦点、逐个 Esc 关闭、重开。
- `tools/verify/qr_check.py`：可用 OpenCV 独立解码单测导出的矩阵。

人工补充两项（自动化环境给不了）：

- 结果行右键「预览」连开 3–4 次，每次之前先让别的程序在前台：每次都新开一个窗口、都到前台，前几个保持打开且互相错开；逐个 Esc 关闭。
- 预览开着时锁屏再解锁、显示器关再开、换虚拟桌面再回来：窗口内容仍在，不出现整片黑色。

发版记录见 [validation-0.2.0.md](validation-0.2.0.md)。Wi-Fi 载荷、密码读取失败、开放/企业网络和图片分享测试归 ra9fael.wifi 管理。

人工验收：宿主菜单快捷键、深浅色主题、缩放、手机扫码。自动解码不代表已完成真实手机连接测试。
