# 二维码插件规格（v0.2.0）

本插件只注册 `qr`（别名「二维码」）。输入文本或链接生成二维码，留空读取剪贴板文本；没有文本时显示提示行。未知或已经删除的命令不返回结果，也不执行动作。

结果行显示内容类型（URL / 文本）、QR 版本、ECC 级别与编码字节数。Enter 复制图片，Ctrl+Enter 打开预览，Shift+Enter 保存 PNG 到 `%USERPROFILE%\Pictures`，文件名冲突时添加序号。预览弹出后立即激活并获取键盘焦点；Esc 或点击窗外关闭。重复打开先关闭并释放旧窗口。

编码器支持版本 1–40、L/M/Q/H 四种纠错级别。设置包括纠错级别、模块尺寸、留白、深浅颜色；越界设置回退默认值。超过当前容量时显示错误，不生成图片。

Wi-Fi 共享由 ra9fael.wifi 负责，二维码插件不枚举 WLAN 配置、不读取密码、不拼接 Wi-Fi 载荷。任意输入仍按原始文本编码。

权限：clipboard:read、clipboard:write、ui、Pictures 写入。运行结构为 qr.exe 引导器 + QrApp.dll，使用宿主 Qt 6.12；不提权、不联网。只有用户执行保存动作才写出 PNG。
